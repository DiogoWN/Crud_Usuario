Tecnologias Utilizadas: <br>
° Front-end: HTML5, CSS3, JAVASCRIPT <br>
° Back-end: Node.js, Express.js <br>
° Banco de Dados: Mysql

Funcionalidade: <br>
° Cadastrar Usuário: Cadastra o usuário via um formulário  <br>
° Lista de Usuário: Mostra uma lista dos usuários criados <br>
° Editar Usuário: Caso tenha digitado alguma informação errada pode modificá-la <br>
° Deletar Usuário: Caso o usuário não queira mais ter uma conta <br>

Dependências: <br>
° npm install <br>
° npm install express <br>
° npm install mysql2 <br> 

Como executar o projeto: <br>
1- Abrir o terminal (Atalho: Ctrl + ') <br>
2- cd Painel_Administrativo <br>
3- cd Api_Usuario <br>
4- Adicionar o banco de dados e criar a tabela (usuarios) <br>
  4.1 - Colocar as credenciais de acesso ao banco (host, usuário, senha, database) <br>
5- node server.js (Para iniciar o servidor) <br>
